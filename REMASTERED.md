# Animal Cup Remastered — Project Identity

## About this repository

Animal Cup Remastered is a community-developed remastered version of the original Animal Cup experience.

This document exists to make the relationship between the original game and this repository clear to contributors and visitors.

## Original project

The original Animal Cup experience was published through HappySeeds:

- Original game: https://app-ce3abc4512.happyseeds.space/
- Platform: https://happyseeds.ai/

## Remastered project

- Repository: `rahmanjimmy504-code/animal-cup-remastered`
- Project name: **Animal Cup Remastered**
- Purpose: continue developing a modern, mobile-friendly web version inspired by the original Animal Cup concept.

## What makes this a remastered project?

The repository is intended to provide a modernized codebase, improved web deployment, mobile support, and a foundation for future gameplay and community improvements.

## Attribution

The original Animal Cup experience and its creators/platform are acknowledged. This repository should not be presented as the original Animal Cup repository or as an official HappySeeds repository unless that relationship is explicitly established.

## Development

The project uses Next.js, React, Pixi.js, OpenNext and Cloudflare Workers. AI-assisted development tools, including Claude Code, have also been used during development.
